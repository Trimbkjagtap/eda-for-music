The 10 Research Exercises

Each Jupyter notebook is one self-contained exercise that answers a specific research question. They build on each other — work through them in order for the clearest understanding.

What is a Jupyter notebook? It's a document that mixes text explanations with runnable Python code and live output (charts, tables). Open them with jupyter notebook in the project root. Run each cell top-to-bottom.
01

Catalog Coherence — Audio Variance

notebooks/01_catalog_coherence.ipynb
Signal 1 fig1_catalog_coherence.png Kaggle dataset PCA

"Do ghost artists produce songs that all sound identical to each other?"

Method: Load the Kaggle dataset. For each artist, compute the total variance across 4 audio features (danceability, energy, valence, acousticness). Run PCA (Principal Component Analysis) to reduce 4 features to 2 dimensions for visualization. Draw a scatter plot with 1-sigma confidence ellipses around each artist's tracks.

Key finding: Ghost artists have variance 12.5× lower than organic artists (p < 0.001). On the PCA scatter plot, ghost artist tracks cluster in a tiny blob in one corner; organic artists spread across a wide ellipse.

Key numbers:

  • Ghost artist mean total variance: ~0.009–0.013
  • Organic artist mean total variance: ~0.085–0.183
  • Threshold chosen: variance < 0.050 = suspicious
Beginner tip: PCA sounds scary but the intuition is simple: we have 4 numbers per track (danceability, energy, valence, acousticness), and we want to draw them in 2D. PCA finds the 2 "directions" that preserve the most variation — essentially compressing 4D data into 2D without losing too much information.
02

Playlist Entropy — Aesthetic Coherence

notebooks/02_playlist_entropy.ipynb
Signal 2 fig2_playlist_entropy.png Spotify API Shannon Entropy

"Do playlists that ghost artists target have unnaturally low diversity?"

Method: Fetch 3 playlist types from Spotify: editorial (curated by Spotify), fan-created (user-made), and ghost-suspect (ambient/relaxation playlists where ghost artists concentrate). For each playlist, compute Shannon Entropy of the audio features across all tracks.

What is Shannon Entropy? A number measuring diversity. High entropy = high variety. Low entropy = everything sounds the same. Formula: H = -Σ p_i × log₂(p_i)

Key finding: Ghost-suspect playlists have lower entropy (H ≈ 2.51) than fan playlists (H ≈ 2.89). Ghost artists deliberately target these low-diversity playlists because their monotonous output fits perfectly and goes unnoticed.
Beginner tip: Think of entropy like a fruit salad. A salad with 5 different fruits has high entropy. A bowl of only apples has low entropy. Ghost artist playlists are the all-apple bowl.
03

ISRC Join — Production Company Network

notebooks/03_isrc_join.ipynb
Signal 3 fig3_isrc_join.png + bipartite_interactive.html Neo4j Bipartite Graph

"Can we find the production companies behind ghost artists by tracing ISRC codes?"

Method: Query Neo4j for all tracks and their ISRC codes. Extract the registrant code (characters 3–5 of the ISRC). Build a bipartite graph: artists on one side, production companies on the other. Draw edges where an artist has tracks registered by that company.

What is an ISRC? International Standard Recording Code — a unique identifier embedded in every published song. Format: DE-A4X-21-00001. The middle 3 letters identify the registrant (production company).

Key finding: In our 4-artist seed set, no production companies are shared between artists. This is expected — sophisticated fraud rings use separate registrants per artist to avoid exactly this pattern. The signal becomes powerful at scale (hundreds of artists).
Common mistake: Students often expect to find shared ISRC prefixes immediately. Don't be disappointed when you don't — this is the correct result for our small seed set. The graph is still valuable for visualizing concentration within each artist.
04

Bipartite Neighborhood — HHI Concentration

notebooks/04_bipartite_neighborhood.ipynb
Signal 6 fig4_bipartite_neighborhood.png Neo4j HHI Formula

"Is one production company monopolizing a ghost artist's catalog?"

Method: For each artist in Neo4j, compute how many tracks are registered by each production company. Then calculate HHI: Σ(fraction²) for each company. A single company controlling everything = HHI near 1.0 (monopoly). Equal distribution = HHI near 0.0.

Key finding: RWN HHI = 0.672 (real ISRC-derived value; earlier proxy estimate was 0.88). Nils Frahm HHI = 0.00 (tracks distributed across multiple labels). Mann-Whitney p=0.003 (n=3 ghost vs 30 organic; bootstrap 95% CI [0.567, 0.900]). This was the single most discriminative signal in the seed set.

Real ISRC-derived HHI values:

ArtistHHI (real)Interpretation
Relaxing White Noise0.672High concentration — one German registrant dominates
Meditation Relax Club0.515High concentration — one Italian company dominates
Calmo0.452Moderate concentration (label: candidate, not journalist-confirmed)
Nils Frahm0.000Independent — own label, no concentration
Beginner tip: HHI is the same formula used by economists to detect monopolies (e.g., the US Department of Justice uses it for antitrust analysis). A score above 0.25 is considered "highly concentrated" in economics. Ghost artists score 2–4× above that threshold.
05

Recommendation Walk — Release Cadence

notebooks/05_recommendation_walk.ipynb
Signal 2 fig5_recommendation_walk.png + fig5b_hop_decay.png Spotify API Closure Rate

"Do ghost artists upload their entire catalog in sudden bursts rather than releasing music gradually over time?"

Method: Fetch all album release dates for each artist. Sort them in time order. Compute consecutive gaps (days between each release and the next). Key metric: closure rate = fraction of consecutive pairs where gap ≤ 1 day. Also compute burst ratio (max releases in any 7-day window ÷ total releases) and hop decay (how many new release dates appear in each time quartile).

Key finding: Meditation Relax Club closure rate = 95% — 95% of their albums were released within 1 day of the previous one. This is physically impossible for a human musician writing and recording music. Nils Frahm: 0% closure, with median gap of 98 days between releases.
Beginner tip: The "recommendation walk" in the notebook title refers to how we traverse the Spotify recommendation graph to discover connected artists — but the core output is simply the release date analysis. Don't get confused by the name.
06

Signal Testing — All 7 Signals on 4 Artists

notebooks/06_signal_testing.ipynb
All 7 Signals fig6_signal_radar.png + fig6b_signal_heatmap.png All data sources

"When we run all 7 signals simultaneously, which ones are most useful for separating ghost from organic artists?"

Method: Run each signal module on all 4 study artists. Normalize scores to [0,1]. Compute discrimination gap (difference between mean ghost score and organic score) for each signal. Visualize as a radar chart (spider web) and a heatmap.

Key findings:
— S6 (HHI) most discriminative: gap = 0.574
— S4 (Catalog Density): gap = 0.477
— S2 (Cadence Closure): gap = 0.389
— Any two-signal combination from {S2, S4, S6} achieves 100% accuracy
— S7 surprise: RWN has 353M YouTube views — high cross-platform is not a legitimate indicator in the ambient genre
Beginner tip: The radar chart is a 7-sided spider web. The further out from the center on any "spoke," the higher the suspicion score for that signal. Ghost artists should have a large polygon shape; organic artists should have a tiny one.
07

Agent Crew — Autonomous Pipeline Test

notebooks/07_agent_crew_test.ipynb
CrewAI LLM Integration Experimental

"Can we build an autonomous AI crew that runs the entire analysis pipeline without human guidance?"

Method: Uses CrewAI to orchestrate 4 specialized agents: a Crawler (fetches data), a Fingerprint Analyst (computes signals), a Graph Builder (analyzes ISRC network), and a Verdict Agent (synthesizes a final report). Each agent has a role, goal, and backstory, and they pass data to each other in sequence.

Key finding: The pipeline mode (no LLM calls) runs correctly and efficiently (2–5 seconds per artist). The full CrewAI mode with GPT-4o adds a natural language synthesis layer but is much slower and more expensive. Both produce correct verdicts on the 4 study artists.
Beginner tip: CrewAI is a framework for building teams of AI agents where each agent has a specific job. It's like a company org chart, but for AIs. You don't need to understand it deeply — the core analysis in this project works without it.
08

GNN Training — GAT vs GCN

notebooks/08_gnn_training.ipynb
PyTorch Geometric fig7_gnn_performance.png GNN 65 artists

"Can a Graph Neural Network that understands artist relationships achieve better accuracy than individual signals?"

Method: Build a 65-node graph (14 ghost, 51 organic). Each node has 8 features (the signal scores + metadata). Add edges: ghost artists fully connected to each other; organic artists connected via k-NN (k=5) based on feature similarity. Train GAT and GCN models. Evaluate on held-out test set. Plot training curves, ROC curve, confusion matrix.

Key finding: Both GAT and GCN achieve 100% test accuracy (6/6 ghost and 7/7 organic correctly classified, zero errors). Feature importance analysis shows all 8 features contribute. Attention weight analysis shows ghost artists attend heavily to other ghost artists — the network topology is a powerful signal in itself.
Beginner tip: Don't be alarmed by 100% accuracy — it's partly because the graph was carefully constructed and the test set is very small (13 examples). Read the limitations section for an honest discussion of what this does and doesn't mean.

Cross-Exercise Integration

notebooks/10_cross_exercise_integration.ipynb
fig8_convergence.png All signals Final synthesis

"When we combine all 10 exercises into one unified analysis, do the signals converge on the same artists?"

Method: Build the convergence matrix: for each artist × exercise, flag whether that exercise detected the artist as suspicious. Count flags per artist. Compute composability accuracy (what accuracy do you get with 1 signal vs. 2 vs. all 6?).

Key finding:
— RWN: 5/5 flags — all 5 exercises flag it simultaneously
— MRC: 4/5 flags
— Calmo: 3/5 flags
— Nils Frahm: 0/5 flags — completely clean
— Any 2-signal combination from the top 3 achieves 100% accuracy
— The convergence is the evidence — independent signals pointing to the same conclusion
Why this matters: This is the strongest argument in the entire research. When 5 completely independent measurements — different algorithms, different data sources, different mathematical approaches — all point to the same artists being fraudulent, that's not coincidence. That's detection.
