How to use the Analyzer

  • Search box: Start typing any artist name. A dropdown appears with matching Spotify artists showing their photo and follower count.
  • Click a dropdown result: Immediately starts analysis via the live pipeline (S2 + S5 + S7 — the signals that work without restricted API data).
  • Quick picks panel: The 4 study artists. Clicking these runs the full 7-signal pipeline using cached Neo4j data — much faster and more complete.
  • Signal bars: Each signal gets a colored bar from 0–1. Red = very suspicious, green = normal. Gray bars with "—" mean that signal couldn't be computed (API restriction).
  • GNN score: Only shown for the 4 study artists. This is the Graph Neural Network's independent verdict.
  • Confidence percentage: Based on how many signals were available. Full 7-signal: up to 85% confidence. Live mode (3 signals): capped at 60–65%.
Live mode limitations: For artists outside the study panel, signals S1 (audio variance), S3 (ISRC), S4 (catalog density), and S6 (HHI graph) are unavailable because the Spotify audio-features and ISRC endpoints were restricted in April 2026. Only S2 (cadence), S5 (title similarity), and S7 (cross-platform) run live.
💡 Tip: Search "Relaxing White Noise" — it's in both the study panel AND searchable, so you can compare the live mode (3-signal) result with the full study-panel (7-signal) result.

🌐 Cross-Platform

A deep dive into Signal 7 — how each artist performs on YouTube and Apple Music, with explanation of the surprising finding that high YouTube views does NOT mean organic.

What's on this page

  • Platform comparison cards: For each of the 4 study artists, shows Spotify follower count, YouTube views, Apple Music presence, and the S7 suspicion score.
  • The surprising finding: Explains that Relaxing White Noise has 353M YouTube views but is still a confirmed fraud — because relaxation content naturally goes viral regardless of who made it.
  • Signal reliability analysis: Explains when S7 is useful (low-presence = suspicious) vs. when it fails (very popular niche content).
Key insight on this page: Cross-platform presence ≠ legitimacy. Ghost factories in the ambient/relaxation niche learned that their content still goes viral on YouTube, giving them a false veneer of legitimacy. S7 works better as a "low score is suspicious" signal than a "high score means organic" signal.

Technical Notes

How the app is built

The web app is a Single-Page Application (SPA) written in plain JavaScript — no React, no Vue, no framework. This was a deliberate choice: simpler to understand, nothing to install, runs anywhere.

Think of it like a slide projector vs. a TV.
A TV (React/Vue app) is powerful but needs electricity, a remote, settings, and maintenance. A slide projector just needs a light bulb and a slide. Our SPA is the slide projector — it does exactly one thing (show pages of content) with the simplest possible mechanism: swap out the HTML inside a single <div> when you click a link.

File structure of the frontend

FilePurpose
static/index.htmlThe HTML shell — just a nav, a #page-root div, and a script tag
static/css/styles.cssAll styling — dark theme, colors, animations, responsive layout
static/js/app.jsThe entire application logic — routing, API calls, page rendering (~850 lines)

How navigation works

When you click "Analyzer" in the nav bar, JavaScript calls navigate('analyzer'), which calls renderAnalyzer(), which returns a big HTML string, which gets inserted into document.getElementById('page-root').innerHTML. No page reload happens — it's instant.
