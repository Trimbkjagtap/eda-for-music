The AI Models

GhostTrack uses two types of AI models: rule-based signal scoring (always available) and a Graph Neural Network (for artists in our database). This page explains both, from scratch.

Level 1: What Is a Neural Network?

Think of it like learning to recognize faces.

When you were a baby, you learned to recognize your parents' faces. You didn't follow a rulebook — you just saw their faces thousands of times and your brain learned the pattern. Neural networks work the same way: instead of being programmed with rules, they learn patterns from examples.

We show the network 65 examples of artists (14 ghosts, 51 organic). For each one, we give it 8 numbers describing that artist and tell it the right answer (ghost or organic). The network adjusts itself until it can correctly classify every example — then we use it on new, unknown artists.

Level 2: What Is a Graph?

Think of it like a social network.

Facebook is a graph. Each person is a node. Each friendship is an edge. A Graph Neural Network (GNN) is a neural network that understands graphs — it doesn't just look at one person in isolation, it also looks at who they're connected to and what their connections look like.

In GhostTrack, each artist is a node, and the edges connect artists that share production companies or have similar audio profiles. Ghost artists all cluster together — they share the same few production registrants. That clustering is a massive red flag, and GNNs are specifically designed to detect it.
[RWN] ──── [MRC] | \ / | | [Calmo] | | | [DE-A4X] [IT-B7Z] (company) (company) Ghost artists share production companies → dense cluster Organic artists spread across many different companies

The Two Models: GAT vs GCN

🥇 GAT — Primary Model

Graph Attention Network

The main model. Uses attention to decide which neighbors matter more. When classifying an artist, it asks: "which of this artist's connections are the most suspicious?"

  • 4 attention heads (4 parallel views)
  • 32 hidden units per head
  • ELU activation + 30% dropout
  • 200 training epochs
  • 100% test accuracy

📊 GCN — Baseline Model

Graph Convolutional Network

The simpler comparison model. Treats all neighbors equally — no attention. Included to show that even a simple GNN outperforms non-graph approaches on this task.

  • Standard neighborhood aggregation
  • 32 hidden units
  • ReLU activation + 30% dropout
  • 100% test accuracy (same as GAT)
  • No attention = less interpretable

The GAT Architecture (Layer by Layer)

Input Layer
8 numbers per artist node (see features below). Shape: [65 nodes × 8 features]
↓
GATConv Layer 1 — "Look around you"
Each node looks at its neighbors and decides (via 4 attention heads) which ones to pay attention to. Output: 32 × 4 = 128 values per node. Then ELU activation + 30% dropout (randomly zeroes 30% of values to prevent overfitting).
↓
GATConv Layer 2 — "Make a decision"
Collapses the 128 values into a single attention head (1 head). Output: 1 value per node.
↓
Sigmoid Output — "How likely is this a ghost?"
Squishes the output to [0.0, 1.0]. A value > 0.5 = predicted GHOST. This probability is the "GNN score" shown in the Analyzer.

In Python code:

class GhostDetectorGAT(torch.nn.Module):
    def forward(self, x, edge_index):
        x = self.conv1(x, edge_index)    # GATConv: aggregate neighbors
        x = F.elu(x)                      # ELU activation
        x = F.dropout(x, p=0.3)           # 30% dropout (training only)
        x = self.conv2(x, edge_index)    # Second GATConv
        return torch.sigmoid(x)           # 0.0 to 1.0 probability

The 8 Input Features

Every artist node in the graph has exactly 8 numbers describing it:

🎵
track_count
Total number of tracks in the artist's catalog. Ghosts have very high counts.
📅
closure_rate
Fraction of consecutive releases within 1 day (S2). Ghosts: 80–95%.
⚡
tracks_per_day
Upload velocity. Ghosts produce at machine speed.
📊
hhi
Herfindahl-Hirschman Index (S6). Ghosts: near 1.0 (one company controls everything).
🎼
total_variance
Audio feature variance across the catalog (S1). Ghosts: near 0.0 (all songs sound identical).
⏱️
mean_duration_ms
Average track length in milliseconds. Ghosts optimize for the ~60s streaming window.
🏭
isrc_prefix_count
Number of distinct production companies used. Ghosts: 1–2 (concentrated).
🎸
genre_count
Number of distinct genres. Ghosts stick to one niche (ambient/relaxation).

Honest caveat: 100% accuracy on a 13-sample test set (6 ghost + 7 organic) is encouraging but not proof of real-world generalizability. The graph structure was also carefully engineered — ghosts are fully connected to each other. In a real production setting, you'd need hundreds of verified ghost examples to make a robust claim. This is a proof-of-concept, not a production system.

What Is Attention (in GAT)?

Think of it like reading a report while highlighting important parts.

When you read a long report, you don't give equal attention to every sentence. You skim, but slow down for the important paragraphs. GAT does the same: when analyzing artist A, it looks at all of A's neighbors (production companies, collaborators) but assigns a higher attention weight to the most suspicious neighbors. A neighbor that's a known ghost factory gets a high attention weight; a random collaborator gets a low one.

This makes GAT interpretable: you can visualize which neighbors most influenced the ghost verdict for any given artist.

The Rule-Based Scorer (Always Available)

Before the GNN runs, there's a simpler rule-based scorer that computes a weighted average of the 7 signal scores. This runs for any artist, including ones not in the graph:

# src/agents/verdict.py
overall_score = np.mean([s1, s2, s3, s4, s5, s6, s7])  # only available signals

if overall_score >= 0.65:   verdict = "LIKELY_GHOST"
elif overall_score >= 0.40: verdict = "SUSPICIOUS"
else:                       verdict = "LIKELY_ORGANIC"

The GNN score is shown alongside this as a second opinion. When both agree, confidence is high.
